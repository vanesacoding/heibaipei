# heibaipei

用于精准复刻「余小白 & 梁小黑」定稿形象的 Codex Skill：余小白为 3D 毛绒 CGI，梁小黑为可变形的二维纯黑手绘小人。

## 安装

将整个 `heibaipei` 文件夹复制到：

```text
~/.codex/skills/heibaipei
```

重新打开 Codex 任务后，通过 `$heibaipei` 使用。

示例：

```text
使用 $heibaipei 生成一张 3:4 小红书竖图：余小白看到空气炸锅后眼睛亮起来，梁小黑在旁边沉默记笔记。暖白背景，大量留白，不生成文字。
```

技能内含余小白 3D 身份锚点、梁小黑手绘身份与变形参考，以及双角色混合媒介锚点。生成时必须按出场角色加载对应资产；完整角色表只用于动作和表情参考。
