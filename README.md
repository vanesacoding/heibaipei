# heibaipei

用于精准复刻「余小白 & 梁小黑」定稿形象的 Codex Skill。

## 安装

将整个 `heibaipei` 文件夹复制到：

```text
~/.codex/skills/heibaipei
```

重新打开 Codex 任务后，通过 `$heibaipei` 使用。

示例：

```text
使用 $heibaipei 生成一张 3:4 小红书竖图：余小白看到空气炸锅后眼睛亮起来，梁小黑在旁边沉默记笔记。暖白背景，大量留白，不生成文字。
```

角色定稿图位于 `assets/heibaipei-character-reference.png`，生成时必须作为最高优先级参考。
